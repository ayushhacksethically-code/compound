# Hinglish (`hg`) Language Guide

Hinglish allows writing programs using common Hindi/English phonetic words.

## Example Program

```hinglish
bhasha="hi"

rakho naam = "Amit"
dikhao "Namaste!", naam

rakho ginti = 1
jabtak ginti chhota ya barabar hai 5 se toh
    dikhao "Ginti number:", ginti
    ginti += 1
khatam

kaam jod(a: int, b: int): int toh
    wapas a + b
khatam

rakho uttar = jod(10, 20)
dikhao "Jod hai:", uttar
```
