# MAN PAGE: Constants (`pukka` / `fixed` / `const`)

## SYNOPSIS
- **Hinglish (`hg`)**: `pukka CONST_NAME = value`
- **English (`eg`)**: `fixed CONST_NAME = value` or `const CONST_NAME = value`

## DESCRIPTION
Declares immutable compile-time constants. Attempting to modify a constant value raises a compiler error.

## EXAMPLES

### Hinglish:
```hinglish
pukka PI = 3.14159
dikhao PI
```

### English:
```english
fixed PI = 3.14159
show PI
```
