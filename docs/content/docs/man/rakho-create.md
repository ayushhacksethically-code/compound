# MAN PAGE: Variable Declaration (`rakho` / `create` / implicit `=`)

## SYNOPSIS
- **Hinglish (`hg`)**: `rakho variable_name = value` or `variable_name = value`
- **English (`eg`)**: `create variable_name = value`, `set variable_name = value` or `variable_name = value`

## DESCRIPTION
Declares or assigns a variable. Compound automatically infers the data type from the assigned value.

## EXAMPLES

### Hinglish:
```hinglish
rakho umar = 25
naam = "Rahul"
```

### English:
```english
create age = 25
name = "Rahul"
```
