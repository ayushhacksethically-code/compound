# MAN PAGE: Loops (`jabtak` / `while` / `har ... mein` / `for each ... in`)

## SYNOPSIS
- **Hinglish (`hg`)**: `jabtak condition toh` ... `khatam` OR `har item mein list toh` ... `khatam`
- **English (`eg`)**: `repeat while condition do` ... `done` OR `for each item in list do` ... `done`

## DESCRIPTION
Repeats code block as long as condition evaluates to true or iterates over lists.

## EXAMPLES

### Hinglish:
```hinglish
rakho i = 1
jabtak i chhota ya barabar hai 5 se toh
    dikhao i
    i += 1
khatam
```
