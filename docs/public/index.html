    Compound Programming Language Documentation#

    Welcome to the official documentation for Compound, a simple, compiled, dual-dialect programming language supporting Hinglish (.hg) and Plain English (.eg).

    🚀 Quick Navigation#

    • Getting Started: Toolchain installation, CLI commands (hg/eg), execution pipeline, REPL, and ORC memory management.
    • Hinglish Syntax Guide (.hg): Complete Hinglish dialect reference with code examples (rakho, dikhao, agar/toh, kaam, khatam).
    • English Syntax Guide (.eg): Complete English dialect reference with code examples (keep, show, if/do, task, done).

    📚 Detailed Manual Pages (man)#

    • C FFI Integration: c_ka_kaam / c_func, header imports, pointer arithmetic, C ABI types.
    • Shell & PowerShell Automation: Bash execution ($, chalao) and PowerShell cmdlets (ps_kaam, ps_command).
    • Data Types & Structs: Objects (banao/type), dynamic sequences (seq[T]), Hash Tables (Table[K,V]), and tuples.
    • Standard Library Reference: std/strutils, std/os, std/tables, std/math, std/asyncdispatch, std/times.
