MAN PAGE: Custom Data Structures (banao / type / object)#

SYNOPSIS#

  • Hinglish (hg):

    banao StructName = object
    field1: type1
    field2: type2
khatam

  • English (eg):

    type StructName = object
    field1: type1
    field2: type2
done

DESCRIPTION#

Defines custom record/object structures with typed fields.

EXAMPLES#

Hinglish:#

banao User = object
    naam: string
    umar: int
khatam

rakho u = User(naam: "Rahul", umar: 20)
dikhao u.naam
