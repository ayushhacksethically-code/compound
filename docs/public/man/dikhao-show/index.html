MAN PAGE: Output Command (dikhao / show / print)#

SYNOPSIS#

  • Hinglish (hg): dikhao expression1, expression2, ...
  • English (eg): show expression1, ... or print expression1, ...

DESCRIPTION#

Prints text, numbers, or variable values to stdout with automatic formatting.

EXAMPLES#

Hinglish:#

dikhao "Namaste World!", 100

English:#

show "Hello World!", 100
print "Welcome!"
