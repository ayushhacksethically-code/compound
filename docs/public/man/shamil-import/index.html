MAN PAGE: Module Imports (shamil_karo / import_karo / import / use)

SYNOPSIS

  • Hinglish (hg): shamil_karo module_name or import_karo module_name
  • English (eg): import module_name or use module_name

DESCRIPTION

Imports standard Nim / C libraries (such as os, strutils, math, times, json, etc.) into your Compound workspace.

EXAMPLES

Hinglish:

shamil_karo os
shamil_karo strutils

English:

import os
use strutils
